# Contributing to BuzzHunt

Thanks for your interest in improving BuzzHunt.

## How to Contribute

1. Fork the repo.
2. Create a branch for your feature or fix.
3. Keep the change focused and easy to review.
4. Test the affected workflow locally.
5. Submit a PR with a clear description of what changed.

## Guidelines

- Do not commit `.env`, credentials, API keys, cookies, browser profiles, scraper output, logs, or database exports.
- Prefer small, readable changes over broad rewrites.
- Keep frontend changes consistent with the existing vanilla HTML/CSS/JS structure.
- Keep backend changes consistent with the existing Express route/service/model layout.
- Treat scraper changes carefully. Document platform assumptions and rate-limit considerations.
- Add or update setup notes when a change introduces a new required environment variable.

## Security

If you find a security issue, do not open a public issue with secrets or exploit details. Contact Mukh.1 through https://mukh.one.
